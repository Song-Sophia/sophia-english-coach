# Sophia English Coach

这是一个无需安装的离线网页。双击 `index.html` 即可在浏览器中打开。

## 每天怎么用（10–15 分钟）

1. 在「今日计划」完成待复习卡片和当天的新词目标（可设为 10 / 15 / 20 / 30 张）。
2. 切到「中文说英文」，看中文后先大声说英文，再点「显示答案」。
3. 选 3–5 个词进入「跟读 + 造句」：听单词和整句、跟读 3 次、可录音回听，最后把词放进与选品、广告、物流或商家沟通有关的一句话。
4. 记不牢的点「再来一次」；能说出的点「认识了」。系统会在 1、3、7、14、30 天后再次出现。

## 包含内容

- 3,105 张词卡：来自 Sophia 词典的工作词、常用短语、进阶表达、易混词、日常词和美妆类目词。
- 20 个跨境电商高频词：如 conversion rate、fulfillment、product compliance、sell-through rate。
- 支持搜索、按分类筛选、单词及整句美式语音朗读、浏览器录音回听和本地学习进度保存。

## 注意

学习进度保存在当前浏览器本地；清除浏览器网站数据或换浏览器后，需要重新开始计数。语音朗读依赖浏览器的系统语音功能。
